# Evidências de captura

`capturas.json` registra as tentativas pontuais desta sessão. Arquivos `.txt` contêm somente texto normativo extraído, em UTF-8 e com normalização declarada no recibo.

`capture.sha256` corresponde exatamente aos bytes do arquivo `.txt`. `transportSha256` corresponde ao HTML recebido, cujo corpo não é versionado para evitar scripts e tokens do portal. A captura não comprova vigência, autenticidade jurídica, atualização ou aprovação humana.

Nenhuma captura é executada pelo aplicativo, build ou testes. A manutenção manual está descrita em `../MODULO-1-BASE-JURIDICA.md`.
